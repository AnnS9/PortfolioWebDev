Campus Event Voting System: Student Engagement Platform

Project Overview

The Campus Event Voting System is a web application designed for university communities. The platform allows students to vote on proposed campus events, helping student unions and organizers select the next scheduled activity based on direct peer feedback.

Key Features

  • Student Voting: An interactive polling mechanism enabling students to review proposed events and cast votes for their preferred choices.
  • Admin Control Panel: A restricted management interface providing administrators the ability to add, edit, or remove event proposals and monitor poll results.
  • User Authentication: Secure login and account management to ensure each student participates fairly within the voting process.

Technology Stack

  • Backend: Built using Python and the Flask microframework to handle routing, session management, and application logic.
  • Database: Data is managed using SQLite, providing a structured relational schema for users, event proposals, and vote counts.
  • Frontend: Clean user interface templates styled to provide a clear and accessible experience across devices.
