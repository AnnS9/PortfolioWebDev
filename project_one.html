Adrenalink Web Platform

Adrenalink: Adventure and Extreme Sports Platform

Project Overview

Adrenalink is a responsive web application built to connect adventure and extreme sports enthusiasts across the United Kingdom. The platform solves the common problem of fragmented outdoor information by bringing together activity listings, interactive maps, user reviews, and community discussions into a single hub.

Key Features

  • Map-Based Discovery: An interactive mapping interface lets users explore locations, examine points of interest, and plan routes.
  • Reviews and Ratings: Authenticated users can submit star ratings and qualitative reviews to build trust and guide fellow explorers.
  • Personalization (Tracks): Registered users can curate and save favorite locations to their profile, maintaining access across sessions.
  • Community Forum: A dedicated space for peer interaction, knowledge exchange, and discussion threads.
  • Admin Dashboard: A control panel that equips administrators with tools for content moderation, user management, and data maintenance.

Technology Stack

  • Frontend: Built with React JS and React Router to create a modular, component-based user interface with dynamic rendering and client-side navigation. Leaflet integration provides the interactive mapping features.
  • Backend: Built using Python and the Flask microframework. The backend utilizes a blueprint architecture to manage RESTful API endpoints, session handling, and role-based access control.
  • Database: Application data is structured and stored using SQLite, providing a lightweight, reliable relational schema for users, categories, places, reviews, and forum posts.
  • Deployment and Security: Deployed on Render.com with HTTPS support. Security measures include password hashing, Flask session management, and restricted administrative permissions.

Design and Development Methodology

The project followed an Agile development approach divided into iterative weekly sprints, with feature prioritization guided by the MoSCoW method. Grounded in Human-Centred Design principles, the project prioritized a mobile-first strategy to ensure clarity, accessibility, and usability for users on the move.
